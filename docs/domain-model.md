# Domain Model

- **WorkItem**: an actionable unit representing work, opportunity handling, planning, or follow-up.
- **Event**: an observed fact, note, signal, message, or state transition that happened in time.
- **Decision**: a recorded choice with rationale, outcome, and downstream implications.
- **AgentReview**: structured feedback or approval generated by an agent against a target entity.
- **Artifact**: a generated or attached output such as a proposal, summary, checklist, or report.
- **Relation**: a typed edge connecting entities such as derived-from, blocks, supports, or references.
- **ReviewCycle**: a recurring or ad hoc review process that inspects state and prompts action.
- **SyncLink**: a mapping between a Praxis record and its representation in an external system.

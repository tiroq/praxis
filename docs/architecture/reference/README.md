# Reference Documentation

Reference documents define approved patterns and canonical implementation examples.

## Owner

Architecture team owns reference curation.

## Documents

- [REFERENCE_REGISTRY.md](REFERENCE_REGISTRY.md) - canonical status registry of approved reference categories
- [PATTERNS.md](PATTERNS.md) - approved architecture pattern definitions
- [IMPLEMENTATIONS.md](IMPLEMENTATIONS.md) - canonical implementation examples and adoption criteria

## Rules

- Reference docs are authoritative for style and structure, not product requirements.
- References must never override RFC, ADR, policy, or principles.
- New references are added only after architecture review.

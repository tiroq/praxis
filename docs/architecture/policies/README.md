# Architecture Policies

This directory defines mandatory engineering constraints that sit below ADRs and above Principles in the authority chain.

## Owner

Architecture team owns policy definitions and approvals.

## Active Policy Documents

- [QUALITY_GATES.md](../../development/QUALITY_GATES.md) - mandatory delivery gates and stop conditions

## Policy Rules

- Policies must be implementation-facing and enforceable.
- Policies must reference RFC/ADR authority for every mandatory rule.
- Policies must not duplicate principles or reference examples.
- Policies may evolve without creating new architectural concepts.
